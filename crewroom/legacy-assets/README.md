# Preserved Crewroom materials

These are selected original materials from Crewroom commit `9094868cdf0640797f9e1d72560c7143028dd94a`, preserved under this directory's 0BSD `LICENSE`. They are reference assets, not a second runtime.

- `assets/`: generated portraits, diary atlases, and generation provenance; original reference photos are excluded.
- `src/`: original atlas rectangles, animation primitives, CSS, and diary rendering references. They are not imported by the application and may reference historical modules. Production ports must use the upstream React/token conventions and real server state.
- `docs/CHARACTERS.md`: character/personality reference.
- `PREVIOUS-README.md` and `THIRD_PARTY_NOTICES.md`: historical product and rights record. Their old feature/readiness claims apply only to the former application, not this migration.

The complete old source and rollback point remain in the existing Git history and original checkout. No contents from `discarded-implementation` were reused.
