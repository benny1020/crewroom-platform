web

## Product Purpose

Crewroom is a Korean-first desktop workspace for one team's shared AI agents, built on the complete Paperclip control plane. Users find colleagues in Team lead / Development / Operations / QA, inspect observed execution, continue task workrooms, choose their own default assistant, and request versioned team skills through ordinary tasks.

The confirmed direction is a dense, calm work tool. Existing Paperclip semantic tokens, controls, authorization, routing, comments, wake queue, sessions, workspaces and artifacts remain authoritative. The original generated plush colleagues and Pomeranian 미미 carry the approved character identity. Stable metadata keeps that identity when an agent is renamed. Work poses reflect fresh observed runs and tool actions; queued and paused poses convey waiting or rest. The twelve-scene sample gallery is explicitly labeled. Reduced motion and the motion switch stop loops; decorative mascot placements stay still.

Departments are display metadata, not access boundaries. A default assistant is a per-user preference over a shared agent, not an independently owned private agent or private memory. Conversation privacy comes from the server's private issue contract. Team lead/member view is presentation only; creation and assignment controls consume server capabilities.

Real API states are required: loading, empty, stale/unavailable, error, denied and ready. No synthetic progress, fake activity, fixture replies or invented metrics appear in production. A skill-generated task records a use request and version reference; it does not certify the execution runtime used that snapshot. Runtime/provider/GitLab credentials and their live qualification are separate from the UI.

The upstream dashboard and administration routes remain available. Crewroom surfaces are Korean; the complete upstream product is not represented as fully translated.
