# Crewroom character assets

These are unchanged copies of original Crewroom generated bitmap assets from `crewroom/legacy-assets/assets/`, under the root license's scoped Crewroom 0BSD terms. Creation notes and the upstream source receipt remain alongside the originals. Paperclip assets keep their MIT attribution.

`character-manifest.ts` maps twelve stable IDs to portraits and measured atlas crops. Names may change without changing character identity. `pom` remains an alias for `mimi`; the original ten plush colleagues remain available. CSS crops the original bitmaps without editing them.

미미, 루루루 and the otter have twelve illustrated scenes. Observed current run state and tool names select production work poses. A tool name never establishes success. Available/unknown colleagues stay still; queued and paused poses show waiting/rest. Other plush colleagues use their own portrait with small activity props. The explicit sample gallery is labeled separately from live execution.

Reduced motion, the user's motion switch, document visibility and offscreen visibility stop loops. No model credentials or execution results are bundled with these assets.
