# Crewroom 화면과 캐릭터 동작

`media/`의 화면은 격리된 로컬 인스턴스의 API를 읽어 캡처합니다. 모델 제공자 자격 증명, 실제 AI 응답, 성공적인 업무 수행을 증명하는 자료가 아닙니다. 로컬 초기 구성의 동료는 연결 준비를 위해 일시 정지 상태로 유지합니다. 검증용 업무가 화면에 포함되면 해당 제목과 설명에 검증용임을 표시합니다.

원래 봉제 캐릭터 10종과 미미·루루루를 그대로 사용합니다. 에이전트 이름을 바꿔도 `metadata.crewroom.characterId`는 유지합니다. 미미·루루루·수달은 코드 수정, 자료 확인, 검사, 검토, 기록, 대기, 휴식 등을 담은 12개 원본 장면을 사용합니다. 다른 캐릭터는 자신의 모습에 작은 작업 소품을 붙입니다. 원본 비트맵은 수정하지 않고 CSS로 필요한 장면만 잘라 표시합니다.

실제 화면의 작업 장면은 새로 확인한 실행 상태와 현재 도구 기록으로 고릅니다. 진행 중이라는 사실이 검사 통과나 업무 완료를 의미하지 않습니다. 실행 대기는 대기 장면, 일시 정지는 휴식 장면으로 구분합니다. 상태를 읽지 못하면 작업 모션을 보여주지 않습니다.

**미미의 동작 미리보기**는 명시적인 샘플 갤러리입니다. 12개 상태와 움직임을 살펴보는 기능이며 실제 동료가 그 업무를 실행 중이라는 뜻이 아닙니다. GIF에도 갤러리의 샘플 안내를 함께 남깁니다.

캐릭터 동작은 상단의 동작 스위치, 운영체제의 동작 줄이기 설정, 문서가 숨겨진 상태와 화면 밖 상태를 따릅니다. 버튼과 텍스트, 업무 상태 정보는 그대로 유지됩니다.

캡처는 아래 명령으로 재현합니다. 브라우저와 모델 실행을 동시에 시작하지 않습니다. 스크립트는 하나의 브라우저와 컨텍스트만 사용하며 종료 시 닫습니다. GIF 변환은 브라우저 종료 후 진행하며 임시 프레임도 제거합니다.

```sh
node scripts/crewroom-capture.mjs
# 명시적 샘플 동작 GIF를 함께 만들 때
CREWROOM_CAPTURE_GIF=1 node scripts/crewroom-capture.mjs
```

GIF는 FFmpeg를 사용하며, `CREWROOM_GIF_PYTHON`에 Pillow가 설치된 Python 경로를 지정해 같은 프레임을 GIF로 저장할 수도 있습니다. 브라우저 실행 파일을 별도로 지정해야 하면 `CHROMIUM_EXECUTABLE`을 사용합니다. 캡처 경로·화면 크기·가로 넘침·브라우저 오류·동작 줄이기 검사 결과는 `media/capture-receipt.json`에 기록합니다. 오류 상태·읽기 전용·빈 데이터의 별도 검증 결과는 검증 보고서에서 실제 API와 응답 대체 검사를 구분해 기록합니다.
