# 크루룸 · 공개 프로토타입 개편 방향

> 2026-10-17 변경: 현재 정책·상태·Paperclip 재사용 경계·서버 복구 계약은 [리뷰 반영 확정 설계](DESIGN_IMPLEMENTATION.md)가 기준입니다. 이 문서의 기존 구조에 추가 적용합니다.

2026-10-16. 대상은 큰 데스크톱 화면에서 일하는 팀이다. 기존 목업의 네 부서와 캐릭터를 유지하고, 조사에서 확인한 업무·실행·기억·공유 모델을 실제 로컬 상호작용으로 옮긴다.

제품의 중심은 **서버에 상주하는 공용 에이전트를 워크스페이스 구성원이 함께 쓰는 것**이다. 후속 화면은 팀 오피스 → 공용 에이전트 → 공유 대화·업무를 기본 흐름으로 삼는다. 같은 에이전트의 업무·기억·스킬을 이어서 사용하고 개인 비서는 보조 기능으로 둔다. [제품 목표와 서버 구현 완료 기준](SHARED_AGENTS.md). 현재 목업의 화면·동작과 후속 설계를 구분한다.

## 시각 언어

- 배경 `#faf9f7`, 표면 `#ffffff`, 본문 `#292b34`, 보조 본문 `#676971`, 실행/선택 `#5956b0`, 판단 대기 `#835b0c`, 완료 `#20755d`.
- 한국어 시스템 고딕을 본문에 사용한다. 제목 26px, 구역 제목 17px, 본문 14px. 정보의 위계는 크기·간격·굵기로 만든다.
- 캐릭터가 있는 네 부서의 공간이 제품의 중심 이미지다. 주변 탐색·업무 기록·설정은 차분한 목록과 구분선으로 구성한다.
- ‘무엇을 하고 있는지’와 ‘내가 무엇을 결정해야 하는지’를 함께 보여 준다. 실제 서버가 연결되지 않은 로컬 시연이라는 상태를 항상 읽을 수 있게 둔다.

```text
브랜드 / 빠른 찾기 / 업무 맡기기 / 시연 사용자
├ 탐색·부서별 동료 ┬ 오피스·확인할 일·인계 흐름 ┬ 선택한 동료와 업무
│ 개인 비서       │                               │ 실행 상태·최근 변화
│                 └ 업무 → 진행 / 대화 / 결과 / 실행 기록
└ 설정                   동료 → 여러 대화 / 스킬 / 기억
```

## 반영할 상호작용

1. 에이전트와 개별 대화를 구분한다. 새 대화를 만들고 전환하며 대화의 공유 범위를 별도로 바꾼다.
2. Task와 Run ID를 구분한다. 실행할 때 설정·스킬 버전을 고정하고 순서가 있는 이벤트를 남긴다.
3. 스킬 장착과 적용 버전을 보여 준다. 새 버전을 게시해도 진행 중인 실행의 버전은 유지한다.
4. 개인 비서의 설정과 기억은 사용자 전환 뒤 분리해 보여 준다. 공유 대화가 개인 기억 전체를 공유하지 않는다.
5. 새로고침 뒤 로컬 상태를 복원한다. 실행 중이던 작업은 재개 대기로 바꿔 사용자가 다시 시작한다.
6. 실제 렌더링한 화면과 조작을 캡처해 README의 스크린샷·GIF로 사용한다.

## 검토

일반적인 지표 카드 대시보드로 전면 교체하는 대신 기존의 부서별 공간에 업무·실행의 근거를 연결한다. 캐릭터 모션은 시연 상태에서만 작동하고, 모션 중단과 reduced-motion을 지원한다. 모바일은 이번 범위에서 제외한다. 실제 서비스의 인증·서버 격리·장기 기억 품질을 브라우저의 표시 동작으로 입증하지 않는다.
