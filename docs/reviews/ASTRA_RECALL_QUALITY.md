# Astra 기억 품질 보호 리뷰 · 0.11.1

2026-10-19, gpt-6-astra의 독립 읽기 전용 리뷰. [검토한 11개 파일의 SHA-256](../evidence/0.11.1/reviewed-files.json), manifest hash `c7829f14b3d646b9222b7fedd02748b5a54466e1c63c22dac834a4e825953721`에 결부된다. 최종 11개 파일이 모두 일치함을 리뷰어가 확인했다.

검토 중 발견한 P1 두 건을 수정했다.

1. 질문 embedding이 성공해도 원문의 cache가 누락·실패·진행 중·구버전이면 `no_matches`로 정상 완료할 수 있었다. 현재 권한·기간·에이전트·의존 근거를 만족하는 원본과 최신 ready cache를 같은 SQL snapshot에서 비교한다. 불완전하면 완료를 막는다.
2. 이전 실행의 고정 입력에 `matched`/`no_matches`만 있으면 검증을 우회해 재개할 수 있었다. `semanticCoverageVersion=1`을 새 실행의 snapshot과 input hash에 함께 고정한다. 증거 없는 과거 snapshot을 수정해 승인하지 않고 새 실행을 요구한다.

연결 장애·용량 초과·고정 profile 변경·혼합 벡터 차원도 정상 답변 완료로 전환하지 않는다. 검증된 빈 corpus와 정상적인 검색 무일치는 작업할 수 있다. 키워드 검색만 설정한 환경의 기존 동작은 유지한다.

최종 리뷰에서 **검토 범위의 남은 필수 P0/P1/P2를 발견하지 못했다.** 리뷰어는 별도 PostgreSQL schema의 독립 품질 회귀 **18/18 통과**, 실패·skip 0을 확인했다. 구현자의 최종 전체 로그 209개·빌드·복원 성공도 확인했다. 독립 18개는 전체 검사 수에 중복 합산하지 않는다.

실제 생성·embedding 모델 호출은 0회다. 이 판정은 검색 준비·장애·재개 시 완료 차단 계약의 검증이며 실제 답변 품질이나 대규모 의미 검색 처리량의 입증이 아니다. [품질 기준과 한계](../QUALITY.md) · [전체 검증](../SERVER_VERIFICATION.md)
