0.15.4의 검토 대상은 기본 개발 동료와 강아지 이름, 이전 기본 저장값의 복원, 커스텀 이름 보존, 같은 ID의 업무·기억 연결, 시연 캡션이다. 개인 비서나 새 부서를 추가하지 않는다. [동결 파일](../evidence/0.15.4/reviewed-files.json).

로컬 검증과 CI의 전체 회귀는 [검증 기록](../SERVER_VERIFICATION.md)에서 구분한다. 이전 캐릭터 릴리스의 독립 검사를 이번 검사 수에 더하지 않는다.

28개 파일과 bundle `98e4c593dbbecc79a019c10aa237829006fa689b98f0f996ac1aab3f876ad20e`를 검토 전후 대조해 승인했다. 필수 P0/P1/P2 발견은 없고 집중 단위 10/10을 독립 실행했다. 브라우저·배포·복원은 영수증 검토이며 독립 재실행하지 않았다. 운영 스크립트를 실행하지 않았으며, 이름·설정 버전·시스템 감사 이벤트만 바꾸는 범위를 확인했다.
